# Release Notes

The release notes of a version list the issues that were fixed in it, so you can see what a release contains.

## Open the release notes

* On an issue, click the **fixed version** in the properties panel.
* In the administration, open the **Versions** tab of a product (see [Products](../administration/issues/products.md#versions)) and click the release notes link of a version.

## What the page shows

* The product and the version, with its status, release date, link and description.
* The issues that have this version as **fixed version**, grouped by issue type. Each issue is shown with its key, which opens the issue.

You only see the issues that you may see yourself (see [Access](issues/README.md#access)). Another person may therefore see a different list for the same version. If you may not see any issue of the version, the page says that no issues have been fixed yet, or that you may not see them.

{% hint style="info" %}
The release notes are filled from the field **Fixed version** of the issues. Set it when you resolve an issue (see [Edit Issue](issues/edit-issue.md)).
{% endhint %}
