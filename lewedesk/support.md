# Support

## Reporting problems and asking questions

For problems with LeweDesk itself and for feature requests, please use the GitHub issue tracker:

* [github.com/glewe/lewedesk/issues](https://github.com/glewe/lewedesk/issues)

The same link is shown on the **About** page in the _Help_ menu.

When you report a problem, please include:

* the LeweDesk version (see **Help** → **About**)
* what you did, what you expected and what happened instead
* a screenshot, if it helps
* the version of PHP and MySQL/MariaDB, for installation problems

## Support for your own installation

Questions about issues in your own LeweDesk installation (for example, about a product your company supports) go to the support team that runs it. Their email address is configured by the administrator in the system settings (_Support Email_). See [Settings](../administration/system/settings.md).
